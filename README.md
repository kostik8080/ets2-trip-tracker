# ВТК-ПЭК: трекер рейсов ETS2

Записывает рейсы в Euro Truck Simulator 2 и начисляет за них очки: пробег, топливо,
груз (масса, хрупкость, ценность, опасность), заработок, повреждения, штрафы, превышения.

## Что нужно

1. **Плагин телеметрии** `scs-telemetry.dll` ([RenCloud/scs-sdk-plugin](https://github.com/RenCloud/scs-sdk-plugin))
   встроен в трекер. В окне трекера нажмите **«Установить плагин»** в карточке «Сейчас»:
   трекер найдёт игру в библиотеках Steam и положит плагин в
   `Euro Truck Simulator 2\bin\win_x64\plugins\`. Если игра не в Steam — укажите её папку.
   При запуске игра покажет окно о том, что SDK активен: нажмите «ОК».
2. **.NET 8 SDK**: https://dotnet.microsoft.com/download

## Запуск

### Окно (основной способ)

```bash
dotnet run --project src/EtsTracker.App
```

При запуске выберите водителя или зарегистрируйте нового: никнейм, рег. номер, грузовик,
ранг и допуски (ADR, тяжёлые, сочленённые). Рейсы, записанные до регистрации,
достаются первому водителю. В окне:

- **«Сейчас»**: состояние игры и текущий рейс (груз, маршрут, пробег, топливо, урон).
  Галочка «Этот рейс — конвой» отмечает рейс как конвой, ставить её до сдачи груза.
  Кнопка «Демо-рейс» имитирует поездку без игры;
- **«Статистика»**: те же показатели, что на листе «Сотрудники», за текущий месяц и всего;
- **«Рейсы»**: история с расшифровкой очков и зарплаты. Тип поездки и класс груза
  можно поправить вручную, зарплата при этом пересчитается;
- **«Графики»**: пробег, зарплата и очки по дням (30 дней) или по месяцам (12 месяцев);
- **«Ставки»**: ставки компании для ранга водителя.

### Оверлей поверх игры

Кнопка **«Оверлей»** в шапке открывает настройки панели, которая видна прямо в игре:
часы, скорость и ограничение (превышение — красным), груз и маршрут, шкала рейса,
остаток пути, время в пути и прибытие, срок доставки, урон.

- **Время:** реальное или игровое. Игра отдаёт время в пути и срок в игровых минутах,
  реальное = игровое / масштаб времени (в ETS2 около 19). Тот же выбор действует
  и в карточке «Сейчас».
- **Вид:** прозрачность фона (0% — только текст с тенью), размер и цвет текста.
- **Положение:** «Переместить оверлей» → перетащите мышью → «Готово».
- **Ctrl+Alt+O** — показать или скрыть оверлей, не выходя из игры.

Оверлей не перехватывает мышь и фокус, клики проходят в игру. Он виден поверх игры
в оконном режиме (окно можно развернуть на весь экран); поверх исключительного
полноэкранного режима Windows обычные окна не показывает. Настройки — `data\overlay.json`.

### Администратор

Первый зарегистрированный водитель становится администратором компании (★ в шапке).
Только администратор:

- открывает **«Водители»**: список всех водителей, новые водители, ранги, допуски и роль
  администратора для любого водителя;
- меняет в **«Компания»** название и логотип (логотип копируется в `data`);
- правит у рейсов тип поездки и класс груза, удаляет рейсы, запускает демо-рейс.

Обычный водитель в своём профиле меняет только никнейм, номер и грузовик. Новый водитель,
зарегистрированный из окна выбора, начинает стажёром. Снять роль с последнего
администратора нельзя.

**PIN администратора.** Вход под администратором защищён PIN-кодом из 4–8 цифр. При первом
входе администратор его придумывает; сменить — «Водители» → «Сменить мой PIN…». Если
администратор забыл PIN, другой администратор нажимает «Сбросить PIN», и при следующем входе
PIN задаётся заново. В базе хранится только хеш PIN (PBKDF2 с солью). Если PIN забыл
единственный администратор, откройте `data	rips.db` в DB Browser for SQLite и очистите поле
`pin_hash` у этого водителя в таблице `drivers`.

### Консоль

```bash
# демо без игры — проверить подсчёт очков
dotnet run --project src/EtsTracker -- --demo

# обычный режим — запустите трекер, затем игру
dotnet run --project src/EtsTracker

# последние 20 рейсов
dotnet run --project src/EtsTracker -- --history
```

Консоль пишет рейсы водителю, который последним выбирался в окне (по `datapp.json` в своей папке).

Собрать один `.exe` (работает без установленного .NET, можно дать друзьям):

```bash
dotnet publish src/EtsTracker.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish/app
```

Файл `publish/app/EtsTrackerApp.exe` можно переименовать как угодно. Папка `data`
создаётся рядом с ним при первом запуске; чтобы перенести рейсы, скопируйте старую `data` туда же.

## Как считаются очки

```
ядро = км заказа × 1
     × масса        (до ×1.5 при 40 т)
     × тип груза    (+0.3 хрупкий, +0.25 ценный, +0.4 опасный, +0.3 спецтранспорт)
     × целость      (1 − урон × 2; 10% урона = −20%)

итог = ядро
     + 10% ядра, если урон < 0.5%
     + до 20% ядра за расход ниже нормы (норма = 28 + 0.4 л/100 км на тонну)
     + 50 за ручную парковку
     + 50 за езду без штрафов и превышений
     − 100 за каждый штраф
     − 1 за каждую секунду превышения (> лимита + 5 км/ч)
```

Отменённый заказ: −100. Оценка зависит от очков на километр:
S ≥ 1.8, A ≥ 1.4, B ≥ 1.1, C ≥ 0.8, иначе D.
Уровень водителя: `уровень = ⌊√(очки / 100)⌋ + 1`.

## Зарплата ВТК

Считается по листу «Стоимость» таблицы компании, отдельно от очков:

```
зарплата = стоимость груза (доход в игре)
         + км × ставка (до 1000 км — €1.7, до 1500 — €1.9, до 2500 — €2.1, больше — €2.7)
         + надбавка за класс груза по рангу водителя (например, «Водитель 2 класса», ADR — €47)
         + 15% стоимости груза, если рейс в город гаража компании или из него
         + 4% стоимости груза за 5-й и следующие рейсы за сутки
```

Надбавка не начисляется, если класса груза нет в списке для ранга, если у водителя нет нужного
допуска (ADR, тяжёлые, сочленённые) или если для стажёра и младшего водителя груз тяжелее 20 т.

Класс груза определяется автоматически: сочленённый (больше одного прицепа), хави карго
(спецтранспорт), ADR, тяжёлый (от 30 т), дорогостоящий, хрупкий, иначе обычный.
«Важный» и «Срочный» игра не сообщает, их ставят вручную на вкладке «Рейсы».

Повышение в ранге ставится вручную в профиле водителя. В окне видно, сколько конвоев
осталось до следующего звания.

## Настройка

При первом запуске в папке `data` рядом с программой появятся:

- **`scoring.json`**: все коэффициенты формулы, меняйте как хотите;
- **`cargo.json`**: ключевые слова для хрупких, ценных и опасных грузов.
  Точные правила по ID груза задаются в `Overrides`:
  ```json
  "Overrides": {
    "glass_pck": ["Fragile"],
    "cement": []
  }
  ```
- **`company.json`**: название и логотип компании, ставки и надбавки, города гаражей,
  условия званий, список грузовиков;
- **`trips.db`**: база водителей и рейсов (SQLite, открывается, например, в DB Browser for SQLite).
  Базы из версии 0.1 обновляются автоматически, рейсы не теряются.

У окна и консоли разные папки `data`, рядом с каждой программой.

SDK игры не сообщает, хрупкий ли груз, поэтому это определяется по ID груза.
ID последнего груза сохраняется в базе (`cargo_id`), так что каталог удобно пополнять.

## Ограничения версии 0.2

- Если закрыть трекер посреди рейса, этот рейс не сохранится.
- Если запустить трекер посреди рейса, пробег и топливо до запуска не учтутся (это помечается).
- Опоздание с доставкой SDK не передаёт, поэтому оно не учитывается.
- Надбавки за сервер (2-й и 3-й сервер TruckersMP), страховка, банк, гаражи и автосалон
  из таблицы пока не перенесены.
